## 🔍 My Testing Approach

I normally start by understanding the requirements and identifying the main user workflows. I then create or review test scenarios, execute positive and negative cases, check boundary and edge cases, and validate behavior across supported browsers and screen sizes.

When I find a defect, I document clear reproduction steps, expected and actual results, environment information, severity/priority, and supporting evidence. After a fix is provided, I perform retesting and regression testing around the affected area.
